# 写真について

いただいた5枚から切り出して、この10点を作成・設置済みです。
差し替えるときは、**同じファイル名で上書き**すれば反映されます。

## 差し替えをおすすめしたい写真

下の5点は、いただいた画像のなかでは**小さく貼り込まれていた**ものを
切り出したため、元が 283×154 前後しかありません。
いまのレイアウトはその実サイズに合わせて組んであるので粗くは見えませんが、
**元データ（撮影したままのファイル）があれば差し替えてください。**
大きく扱えるようになり、見栄えが一段上がります。

- `hall-hondo.jpg` … 本堂の内陣
- `hall-amidado.jpg` … 阿弥陀堂ホール
- `hall-tsuya.jpg` … 通夜室
- `nokotsudo.jpg` … 納骨堂
- `sanmon-ishimon.jpg` … 石門（504×500。もう少し大きいと理想）

主景の `sunset-shuri.jpg` も横 1584px なので、大きな画面では少しやわらかく出ます。
元データがあれば **横 2400px 以上**での差し替えをおすすめします。

## 割り当てを変えたいとき

たとえば「阿弥陀堂ホールの写真は別のものにしたい」という場合は、
**その写真を `hall-amidado.jpg` という名前で保存して上書き**するだけです。
HTMLをさわる必要はありません。

## 追加でいただけると良い写真

- 御本尊 不動明王（いただいた画像では小さすぎて使えませんでした）
- 阿弥陀堂ホールの内観
- 坐禅会・ヨガ・法話会のようす

## 書き出しのめやす

長辺 2400px / JPEG 品質 78〜82 / 1枚 300KB 以下

```
magick input.jpg -resize 2400x -quality 80 -strip sunset-shuri.jpg
```
