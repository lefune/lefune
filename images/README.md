# 写真の置きかた

`ankokuji.html` はこのフォルダの写真を読みにいきます。
**下の名前どおりのファイル名で、このフォルダに入れるだけ**で反映されます。
ファイルが無いあいだは、その写真の色に近い地色が出るようになっているので、
一枚ずつ足していっても見た目が崩れることはありません。

## 撮り方・切り方のめやす

- **主景（sunset-shuri）** … 文字が右下と左下に入ります。空の面積が広い横位置がきれいに出ます。
- **沿革（aerial-keidai）** … 左半分に文字がのります。**被写体は右寄り**の構図だとよく合います。
- **霊園（reien-churayui）** … 中央に大きく「清ら結」がのります。中央が空いている構図が向いています。
- 縦位置の3枚（石門・納骨堂・不動明王）は、上下を切られても成立する構図が安全です。

## 容量について

写真は 1枚あたり **300KB 以下**（長辺2400pxでJPEG品質75〜80程度）に落としてから
置くと、スマホでの表示が軽くなります。

参考コマンド（ImageMagickがある場合）:

```
magick input.jpg -resize 2400x -quality 78 -strip sunset-shuri.jpg
```
